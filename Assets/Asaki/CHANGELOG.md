# Changelog

所有对 Asaki Framework 的显著变更都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/ )，
并且本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/ )。

## [1.0.0] - 2026-01-31

### 初始发布

#### 核心功能
- **依赖注入系统** - 基于特性的服务注册和自动注入
- **命令模式** - 支持撤销/重做的命令系统，包含命令池管理
- **查询模式** - 类型安全的查询系统，支持缓存和池化
- **事件总线** - Broker 模式的松耦合事件系统
- **Reactive 响应式架构** - 响应式属性绑定系统（原 MVVM 架构升级）
- **状态机** - 灵活的分层状态机实现
- **黑板系统** - 运行时数据存储和共享机制

#### 服务模块
- **音频服务** - 分层音频管理（BGM/SFX/Voice），支持状态机
- **UI 服务** - 窗口管理系统，支持层级和生命周期
- **资源服务** - 基于 Addressables 的资源加载，支持多种策略
- **场景服务** - 场景加载管理和过渡效果
- **对象池服务** - 高性能对象池，支持多种工厂模式
- **存档服务** - JSON 和二进制序列化，支持多存档槽
- **网络服务** - HTTP 请求管理和下载服务
- **计时器服务** - 计时器和调度管理
- **模拟服务** - 游戏循环和 Tick 管理

#### 编辑器工具
- **配置烘焙器** - CSV/JSON 配置转换为二进制资源
- **配置调试器** - 运行时配置查看和调试
- **事件调试器** - 事件总线监控工具
- **上下文调试器** - 依赖注入容器查看器
- **日志仪表板** - 运行时日志查看和过滤
- **图编辑器** - 可视化节点图编辑系统
- **模块仪表板** - 模块管理和配置工具
- **资源工具集** - 批量重命名、查找重复、资源替换等
- **UI 生成器** - UI 代码和预制体生成工具

#### 架构示例
- Counter 示例 - 命令模式和事件系统演示
- MVVM 示例 - 数据绑定和属性系统演示
- SafeCoroutine 示例 - 安全协程使用演示

#### 技术特性
- 模块化设计，按需加载
- 零分配优化（使用 UniTask 和 Collections）
- 完整的编辑器支持
- 详细的日志和调试工具
- 类型安全的设计

### 依赖

#### 必须安装
- **Unity** 2022.3 LTS+ 
- **UniTask** 2.9.0+ - 高性能异步任务库
- **TextMeshPro (TMP)** 3.0.0+ - Unity 官方文本渲染解决方案

#### 推荐安装
- **Addressables** 1.21.0+ - 资源管理系统（非强制要求，但推荐）

#### 自动安装依赖
- Burst 1.8.0+
- Collections 2.1.0+
- Mathematics 1.2.0+

## 版本说明

### 版本号格式
`MAJOR.MINOR.PATCH`

- **MAJOR** - 不兼容的 API 更改
- **MINOR** - 向后兼容的功能添加
- **PATCH** - 向后兼容的问题修复

### 版本标签
- `[Added]` - 新功能
- `[Changed]` - 现有功能的变更
- `[Deprecated]` - 已弃用的功能
- `[Removed]` - 移除的功能
- `[Fixed]` - 修复的问题
- `[Security]` - 安全相关的修复
