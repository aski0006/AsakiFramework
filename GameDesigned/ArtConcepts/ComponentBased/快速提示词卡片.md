## 七、参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| `--ar 1:1` | 正方形 | 角色/塔/图标 |
| `--ar 4:3` | 4:3 | 躯干 |
| `--ar 2:3` | 2:3 | 武器 |
| `--ar 4:1` | 4:1 | 4帧动画 |
| `--ar 6:1` | 6:1 | 6帧动画 |
| `--ar 8:1` | 8:1 | 8帧动画 |
| `--ar 12:1` | 12:1 | 12帧动画 |
| `--ar 16:1` | 16:1 | 16帧旋转 |
| `--stylize 250` | 低 | UI图标 |
| `--stylize 300` | 中 | 标准元件 |
| `--stylize 350` | 高 | Boss/重点 |
| `--quality 2` | 高质量 | 推荐 |
| `--v 6.1` | V6.1 | 推荐版本 |
